# KI-Trader Börsen-Wächter

Prüft werktags abends die Kurse von Apple, Microsoft, Nvidia, Amazon und SAP,
erstellt eine Übersichtsseite (GitHub Pages) und schickt Alarme per Push (ntfy).

Läuft automatisch über GitHub Actions – kein eigener Rechner nötig.
Keine Anlageberatung. Es werden keine echten Orders ausgeführt.
